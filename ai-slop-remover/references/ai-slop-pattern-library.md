# AI Slop Pattern Library — Comprehensive Detection & Remediation Guide

This library catalogues the 22 signature design patterns, visual clichés, and code artifacts commonly generated by AI coding assistants (Cursor, Claude Code, v0, Lovable, Bolt.new) and generic templates. Every entry specifies the code signature, why it fails, its severity rating, and the concrete human-crafted replacement.

## Deep Pattern Diagnostics & Code Transformations

### 1. SLOP-01: The Indigo/Purple Gradient Syndrome
- **Why it looks generic**: AI models heavily weight standard Tailwind presets where `indigo-600` and `violet-600` are the default accent examples in documentation. Millions of landing pages now use this exact gradient, signaling zero custom brand consideration.
- **Problematic Implementation**:
  ```tsx
  // BAD: Indiscriminate purple gradient
  <h1 className="text-6xl font-bold bg-gradient-to-r from-indigo-500 via-purple-500 to-pink-500 bg-clip-text text-transparent">
    Build Faster with AI
  </h1>
  <button className="bg-gradient-to-r from-indigo-600 to-violet-600 shadow-lg shadow-purple-500/25 text-white px-6 py-3 rounded-full">
    Get Started Free
  </button>
  ```
- **Human-Crafted Replacement**:
  ```tsx
  // GOOD: Grounded typography, distinctive monochrome or mineral accent
  <h1 className="text-5xl font-serif tracking-tight text-brand-neutral-900 dark:text-brand-neutral-50">
    Precision typing intelligence for competitive exams.
  </h1>
  <button className="bg-brand-neutral-900 text-brand-neutral-50 hover:bg-brand-neutral-800 dark:bg-brand-neutral-100 dark:text-brand-neutral-900 px-5 py-2.5 rounded-md font-medium text-sm transition-colors duration-150 focus-visible:ring-2 focus-visible:ring-brand-accent focus-visible:outline-none">
    Begin 5-Minute Assessment &rarr;
  </button>
  ```

### 2. SLOP-02: Floating Glow Blobs & Blurry Radial Gradients
- **Why it looks generic**: AI tools inject background blur divs to hide visual emptiness without actually designing meaningful backgrounds or layout structure.
- **Problematic Implementation**:
  ```html
  <!-- BAD: Blobs placed behind empty sections -->
  <div class="relative overflow-hidden">
    <div class="absolute -top-40 -right-40 w-96 h-96 bg-purple-500/30 rounded-full blur-3xl pointer-events-none"></div>
    <div class="absolute -bottom-40 -left-40 w-96 h-96 bg-blue-500/20 rounded-full blur-3xl pointer-events-none"></div>
    <!-- Content -->
  </div>
  ```
- **Human-Crafted Replacement**:
  ```html
  <!-- GOOD: Crisp architectural gridlines or clean background texture -->
  <div class="relative border-b border-brand-border bg-brand-surface py-16">
    <div class="max-w-6xl mx-auto px-6 grid grid-cols-12 divide-y md:divide-y-0 md:divide-x divide-brand-border">
      <!-- High-contrast structured content -->
    </div>
  </div>
  ```

### 3. SLOP-03: Excessive Glassmorphism & Translucent Overlays
- **Why it looks generic**: AI uses `backdrop-blur-md bg-white/10` to simulate Apple-style depth. In practice, it causes severe text-contrast issues, poor mobile performance due to continuous GPU rasterization, and a dated "2021 web3 template" aesthetic.
- **Problematic Implementation**:
  ```tsx
  // BAD: Low-contrast blurry card
  <div className="backdrop-blur-xl bg-white/5 border border-white/10 rounded-2xl p-8 shadow-2xl">
    <h3 className="text-white text-xl font-semibold">Real-Time Metrics</h3>
    <p className="text-gray-400 mt-2">Instant feedback on all telemetry streams.</p>
  </div>
  ```
- **Human-Crafted Replacement**:
  ```tsx
  // GOOD: Solid surface token with high contrast and crisp 1px borders
  <div className="bg-brand-surface border border-brand-border rounded-lg p-6 shadow-sm hover:border-brand-border-hover transition-colors">
    <div className="flex items-baseline justify-between border-b border-brand-border pb-3 mb-4">
      <h3 className="text-brand-text font-mono text-sm tracking-wide uppercase">Telemetry Feed</h3>
      <span className="text-xs font-mono text-emerald-600 dark:text-emerald-400 bg-emerald-50 dark:bg-emerald-950/50 px-2 py-0.5 rounded">LIVE</span>
    </div>
    <p className="text-brand-muted text-sm leading-relaxed">Continuous keystroke cadence sampled at 60 Hz.</p>
  </div>
  ```

### 5. SLOP-09: Identical 3-Card Bento Grid
- **Why it looks generic**: AI models default to 3 identical column containers. Each has an icon in a colored rounded square, a short title, and two lines of filler text. It conveys minimal information while consuming massive vertical height.
- **Problematic Implementation**:
  ```tsx
  // BAD: 3 identical cards
  <div className="grid grid-cols-1 md:grid-cols-3 gap-8">
    {['Fast', 'Secure', 'Scalable'].map(title => (
      <div className="p-6 rounded-2xl bg-gray-900 border border-gray-800">
        <div className="w-12 h-12 rounded-xl bg-purple-500/20 text-purple-400 flex items-center justify-center mb-4">
          <Zap />
        </div>
        <h3 className="text-xl font-bold">{title}</h3>
        <p className="text-gray-400 text-sm mt-2">Engineered from the ground up for maximum performance.</p>
      </div>
    ))}
  </div>
  ```
- **Human-Crafted Replacement**:
  ```tsx
  // GOOD: Asymmetric multi-scale information layout
  <div className="grid grid-cols-1 lg:grid-cols-12 gap-6">
    <div className="lg:col-span-8 border border-brand-border rounded-lg p-8 bg-brand-surface">
      <div className="text-xs font-mono text-brand-muted uppercase">Primary Feature</div>
      <h3 className="text-2xl font-serif font-bold text-brand-text mt-2">Comprehensive Exam Telemetry</h3>
      <p className="text-brand-muted mt-2 text-sm max-w-lg">
        We track backspace cadence, character-level key depressions, and ligature assembly errors to identify your specific bottlenecks.
      </p>
      <div className="mt-6 border border-brand-border rounded bg-brand-surface-2 p-4">
        {/* Real data preview or interactive drill-down */}
      </div>
    </div>
    <div className="lg:col-span-4 flex flex-col justify-between border border-brand-border rounded-lg p-6 bg-brand-surface">
      <div>
        <div className="text-xs font-mono text-brand-muted uppercase">Layout Engine</div>
        <h4 className="text-lg font-bold text-brand-text mt-2">Dual Keyboard Architecture</h4>
        <p className="text-brand-muted text-sm mt-1">Native Devanagari INSCRIPT and legacy Kruti Dev conversion.</p>

      <div className="pt-4 border-t border-brand-border mt-6 text-xs text-brand-muted font-mono">
        Tested across 14 Hindi exam matrices.
      </div>
    </div>
  </div>
  ```

### 6. SLOP-15: Buzzword Copywriting Slop
- **Why it looks generic**: Language models generate abstract superlatives when they lack concrete domain knowledge.
- **Banned Words & AI Tells**:
  - *"Transform your workflow"* $\rightarrow$ Change to: *"Audit your site in under 3 minutes"*
  - *"Seamlessly collaborate"* $\rightarrow$ Change to: *"Share live test links with your instructor"*
  - *"Cutting-edge AI-powered platform"* $\rightarrow$ Change to: *"Built with Node.js and Postgres 17"*
  - *"Elevate your typing journey"* $\rightarrow$ Change to: *"Practice 10-minute Hindi government exam passages"*
  - *"Unlock your potential"* $\rightarrow$ Change to: *"Target 35 WPM required for SSC CHSL qualification"*
